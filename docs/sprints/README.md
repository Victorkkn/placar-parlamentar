# Sprints

Decision 0001 lists sprint notes as an output of the scrum master. The MVP was not run in time-boxed sprints: work was planned and approved **by phase**, so progress is tracked in these places instead:

- Plans, outcomes and deviations: `docs/plans/` (one file per phase).
- What is done and left: `docs/mvp-status.md`; later work: `docs/backlog.md`.
- What was actually done each step, with the checks run: `docs/agent-history/`.
- When a task counts as done: `docs/definition-of-done.md`.

If later work is run in sprints, add one note per sprint here (goal, items, outcome).
