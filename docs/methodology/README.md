# Metodologia

Páginas exibidas no aplicativo, em português do Brasil (decisão 0003). Revisão de redação e neutralidade feita e aprovada pelo responsável pelo projeto em 2026-11-01.

- [Tempo no cargo e cobertura](tempo-no-cargo.md)
- [Presença em sessões deliberativas do Plenário (Câmara)](presenca-plenario.md)
- [Proposições apresentadas](proposicoes.md)
- [Participação em votações nominais](votacoes-nominais.md)
- [Discursos](discursos.md)
- [Resumos](resumos.md)

Regras comuns a todas as métricas:

- **Somente dados oficiais.** As fontes são as APIs de Dados Abertos da Câmara dos Deputados e do Senado Federal.
- **Fonte para cada número.** Todo número tem um link para o registro oficial de onde veio.
- **Somente dias no cargo.** As métricas contam apenas os dias em que a pessoa exercia o mandato dentro do período escolhido.
- **Data dos dados.** Os dados são uma cópia coletada em data informada na tela; o aplicativo não consulta as APIs ao exibir as páginas.
- **Por 365 dias no cargo.** Contagens (proposições, discursos) também aparecem divididas pelos dias no cargo e multiplicadas por 365, para comparar pessoas com tempos diferentes no cargo.
- **Sem juízos de valor.** As descrições informam o que os registros mostram, sem adjetivos de julgamento.
