Regras comuns a todas as métricas:

- **Somente dados oficiais.** As fontes são as APIs de Dados Abertos da Câmara dos Deputados e do Senado Federal.
- **Fonte para cada número.** Todo número tem um link para o registro oficial de onde veio.
- **Somente dias no cargo.** As métricas contam apenas os dias em que a pessoa exercia o mandato dentro do período escolhido.
- **Data dos dados.** Os dados são uma cópia coletada em data informada na tela; o aplicativo não consulta as APIs ao exibir as páginas.
- **Sem classificações.** As descrições informam o que os registros mostram, sem adjetivos ou juízos de valor.
