# Placar Parlamentar

Civic-transparency tool for Brazilian federal legislators, built only from official Câmara and Senado open data. Python backend, React frontend.

## Before any work

1. Read and follow `docs/architecture-rules.md`. Those rules are binding.
2. Check `docs/decisions/README.md` for the status of every decision. Only accepted decisions are rules.
3. Never run `git push` or any other action listed under "Approval gates" without the project owner's explicit approval. Always ask.
4. Log meaningful work in `docs/agent-history/`.

## Where things are

- `README.md`: scope and principles.
- `docs/decisions/`: decision records and index.
- `docs/architecture-rules.md`: binding rules.
- `.claude/agents/`: role agent definitions.
